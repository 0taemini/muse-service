# 공연 조회 운영 기준 부하테스트

## 대상과 시나리오

- 실행일: 2026-09-03
- 부하 발생기: 로컬 Docker의 `grafana/k6:0.57.0`
- 대상: 운영 HTTPS endpoint
- 요청 흐름: 로그인 1회 후 공연 목록 → 공연 상세 → 채팅방 목록 반복
- 요청 성격: read-only
- 사용자 대기시간: 반복마다 1~3초

1 VU와 5 VU smoke test에서 인증과 조회 흐름이 정상 동작하는 것을 확인한 후 20 VU 기준 테스트를 실행했다.

## 해석과 한계

- 20 VU, 약 25 RPS의 읽기 부하에서는 성능 저하나 오류가 관찰되지 않았다.
- VU별 결과는 실행 시점, TLS 연결 재사용, JVM 및 DB 캐시 상태가 달라 직접적인 선형 비교 자료로 사용하지 않는다.
- 테스트 데이터 규모와 Grafana의 JVM, HikariCP, PostgreSQL 지표를 함께 기록해야 병목 여부를 최종 판단할 수 있다.
- 이 결과는 현재 읽기 시나리오의 기준값이며 쓰기, WebSocket, 동시성 처리 성능을 대표하지 않는다.
