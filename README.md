# MuseService

## 1. 프로젝트 개요

밴드 동아리 ‘뮤즈’ 내부 운영을 위한 공연 관리 및 피드백 협업 서비스입니다.

MuseService는 공연 목차 생성, 곡 리스트 관리, 선곡 상태 평가, 합주방 채팅, 라운드 기반 피드백 정리까지 하나의 흐름으로 연결할 수 있는 통합 서비스입니다.

기존에는 공연 정보를 엑셀과 수동 운영 중심으로 관리하던 과정을, 서비스 단에서 구조화하고 협업 가능한 형태로 바꾸는 데 초점을 두고 있습니다.

## 2. 기획 배경

공연 준비 과정에서는 다음과 같은 운영 병목이 발생합니다.

- 공연별 곡 정보를 여러 사람이 나누어 입력해야 하는 점
- 선곡 상태를 일관되게 관리해야 하는 점
- 확정된 곡만 합주방 채팅 대상으로 선택해야 하는 점
- 채팅 리셋과 피드백 종합을 단순 삭제가 아니라 구조적으로 관리해야 하는 점

MuseService는 이러한 문제를 해결하기 위해 공연, 곡, 채팅, 피드백 종합을 하나의 서비스 흐름으로 연결하도록 설계되었습니다.

## 3. 주요 기능 소개

### 1) 공연 생성 및 관리

- 공연 목차를 생성하고 관리할 수 있습니다.
- 공연 아래에 곡 리스트를 등록하고 수정할 수 있습니다.
- 곡별 선곡 상태를 `CONFIRMED`, `NOT_BAD`, `OUT`로 구분합니다.

### 2) 곡 리스트 및 선곡 상태 평가

- 여러 사용자가 동일한 공연의 곡 정보를 공동으로 관리할 수 있습니다.
- 각 곡에 대해 공연 내 선곡 상태를 평가할 수 있습니다.
- 상태 변화에 따라 이후 채팅방 노출 여부가 결정됩니다.

### 3) 합주방 생성

- 확정된 곡만 채팅방 생성 대상 목록에 노출됩니다.
- 사용자 선택에 따라 전체 선택 또는 부분 선택으로 채팅방을 생성할 수 있습니다.
- 채팅방은 공연-곡 단위로 1개만 유지됩니다.

### 4) 채팅 라운드 기반 운영

- 채팅 “리셋”은 메시지 삭제가 아니라 라운드 분리 방식으로 처리됩니다.
- 각 라운드가 독립적으로 관리되며, 대화 흐름을 시간 순서로 보존할 수 있습니다.

### 5) 피드백 종합

- 라운드 종료 시 피드백 데이터를 종합해 저장합니다.
- 마이페이지에서 누적된 피드백 요약을 확인할 수 있습니다.

## 5. 아키텍처 및 설계

### 구성 개요

- 클라이언트: React + Vite + TypeScript
- API 서버: Spring Boot + JPA
- 데이터 저장: PostgreSQL
- 캐시/세션/실시간 보조: Redis
- 파일 저장: AWS S3 연동 이미지 업로드
- 인증: JWT 기반 사용자 인증

### 주요 설계 포인트

- 공연과 곡 정보를 기능 단위로 분리해 관리합니다.
- 채팅방은 공연-곡 기준으로 단일 생성 정책을 유지합니다.
- 채팅 리셋은 삭제가 아니라 라운드 기반 분리로 구현합니다.
- 확정곡만 채팅 생성 대상이 되도록 조회 조건과 서비스 검증을 함께 적용합니다.

### 이미지 처리 파이프라인

이미지 업로드는 S3 기반 Presigned URL 흐름을 사용하며, 업로드된 원본 이미지는 `original/` 경로에 저장됩니다. 이후 S3 이벤트를 트리거로 Lambda가 자동 실행되어 여러 크기의 WebP 이미지를 생성하고 `resized/` 경로에 저장합니다. 최종적으로 CloudFront/CDN을 통해 이미지가 제공되는 구조로 운영됩니다.

### 인증 및 보안 설계

서비스는 JWT 기반 인증을 채택하고 있으며, Access Token은 짧은 수명을 갖는 인증 수단으로 사용하고 Refresh Token은 서버 측에서 안전하게 관리하는 구조를 지향합니다. 특히 XSS와 CSRF를 고려해, 토큰 저장과 쿠키 정책을 보안 중심으로 설계했으며 민감한 인증 정보가 브라우저의 JavaScript 접근 범위에 노출되지 않도록 구성했습니다.

## 6. 실행 방법

### 사전 준비

- JDK 17 이상
- Node.js 20 이상
- npm 10 이상
- Docker Desktop 또는 Docker Engine

### 1) 인프라 실행

```bash
cd backend
docker compose up -d
```

### 2) Backend 실행

```bash
cd backend
./gradlew bootRun
```

Windows PowerShell에서는 아래 명령으로 실행할 수 있습니다.

```powershell
cd backend
.
\gradlew.bat bootRun
```

### 3) Frontend 실행

```bash
cd frontend
npm install
npm run dev
```

### 실행 주소

- Frontend: http://localhost:5173
- Backend API: http://localhost:8080
